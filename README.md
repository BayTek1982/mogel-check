# Bayazit Mogel-Check

Web-App gegen Mogelpackungen: Barcode scannen und sehen, wie sich Füllmenge, Preis und Grundpreis eines Lebensmittels über die Zeit verändert haben. Dazu Zutaten, Allergene, Zusatzstoffe und Nährwerte.

- Daten: Open Food Facts und Open Prices (Lizenz ODbL)
- Eigene Preise werden nur im Browser auf dem eigenen Gerät gespeichert
- Barcode-Scanner: html5-qrcode 2.3.8 (Apache-2.0), lokal in `vendor/`
